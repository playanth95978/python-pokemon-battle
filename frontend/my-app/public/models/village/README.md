# Maisons de village et dresseur

Modèles GLB de [Quaternius](https://quaternius.com), téléchargés depuis https://poly.pizza, sous licence
CC0 (domaine public, aucune attribution requise). Utilisés par Clairbois 3D (`world3d.html`) et le monde ouvert
(`open-world.html`).

| Fichier | Page source | Usage |
|---|---|---|
| `village/fantasy_house_a.glb` | https://poly.pizza/m/BH2XHWUNmF | Maison du départ |
| `village/fantasy_inn.glb` | https://poly.pizza/m/x3ZcGn3jr4 | Maison des soins |
| `village/fantasy_house_b.glb` | https://poly.pizza/m/dcPho4SUA3 | Atelier du village |
| `village/timber_house.glb` | https://poly.pizza/m/RSwoYSLblu | Bâtiments sans modèle attitré |
| `trainer/casual_character.glb` | https://poly.pizza/m/kZ3DmIoGip | Dresseur (animations Idle, Walk, Run) |

Les matériaux unis des maisons reçoivent en jeu le grain des textures Poly Haven (`textures/polyhaven`).
