# Textures Poly Haven

Textures PBR en 1k (JPG) téléchargées depuis https://polyhaven.com, sous licence
CC0 (domaine public, aucune attribution requise). Utilisées par la vue 3D (`world3d.html`).

Pour chaque texture : `_diff` (couleur), `_nor_gl` (normales OpenGL), `_rough` (rugosité).

| Fichier | Page source | Usage |
|---|---|---|
| `sparse_grass` | https://polyhaven.com/a/sparse_grass | Chemins et lit du lac |
| `forrest_ground_01` | https://polyhaven.com/a/forrest_ground_01 | Herbe |
| `clay_roof_tiles` | https://polyhaven.com/a/clay_roof_tiles | Toits |
| `plastered_wall_02` | https://polyhaven.com/a/plastered_wall_02 | Murs |
| `wood_planks` | https://polyhaven.com/a/wood_planks | Pont, portes, colombages |
| `bark_willow` | https://polyhaven.com/a/bark_willow | Troncs |
